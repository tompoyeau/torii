Logos officiels des launchers (PNG/SVG/WEBP).
Le fichier doit être nommé d'après l'identifiant de plateforme :
steam, epic, gog, riot, ubisoft, ea, battlenet, manual.

Ex: epic.png, ubisoft.png, battlenet.png, riot.png.
PlatformIcon.vue les charge automatiquement (import.meta.glob) et
retombe sur l'icône SVG dessinée si le fichier est absent.
